## Known gaps before an official run

1. **Data / indices / generation** have not been re-executed in this environment
   (no DPR dump, no GPU, no network). The code paths were audited but not run with real
   models.
2. **Model families** `gbt`, `mlp`, `deberta` are implemented but only `logreg` has been
   exercised (LightGBM/vLLM/transformers not installed here). `gbt` needs `lightgbm`;
   `mlp`/`deberta` need `torch` + `transformers` and a GPU for reasonable runtimes.
3. **k ablation** (k ∈ {3, 5, 10}) is not automated as a Makefile target yet. Run stage
   04 with `--k 3` and `--k 10` into separate runs, then stages 05–07 with the same
   `--run` and `--k`.
4. **Manual failure verification** (≥ 50 per dataset) is pending: stage 08 writes a
   deterministic sample (`results/tables/failures_<run>.csv`); `docs/failures.md`
   describes the review protocol.
5. **Official-dev numbers** do not exist in this repository yet. `docs/REPORT.md` is a
   stub generated by the report script; it will contain numbers only after a real run.
6. **Git remote**: this checkout was created from the GitHub repository
   `StellarYolk/Pythia`; no push was attempted. `PLAN.md` explicitly says the user
   pushes manually.

## What was fixed in this pass

- `scripts/05_build_labels.py`: missing `json` import.
- `labeling/build_labels.py`: `itertuples()` rows were indexed like dictionaries.
- `router/models.py`: DeBERTa `build_model` passed the model name twice; deprecated
  sklearn `multi_class` removed; temperature fitting now receives probabilities.
- `scripts/06_train_router.py`: feature cache now stores `question` (needed by DeBERTa
  and the complexity baseline), the embedding model/device come from config, missing
  BM25/dense indices degrade to surface features instead of crashing, per-dataset and
  LODO variants implemented, tier-ablation results are accumulated instead of
  overwritten, `--no-primary` protects the primary prediction file.
- `scripts/07_run_eval.py`: oracle/confidence-threshold outputs are aligned to the
  evaluation qid order; O(N²) scoring replaced with vectorised lookup; complexity
  classifier maps its own qids; duplicate feature path removed; success margin corrected
  to the 0–1 EM scale; `variant`/`heldout` metadata propagated.
- `configs/default.yaml`: machine-specific dense-model path removed; success margin
  fixed; analysis defaults added. `trimmed.yaml` records the agreed smaller budget.
- `Makefile` / `run_stage.sh` / `00_setup.sh` / `doctor.py` / `download_model.sh`: all
  machine-specific `/home/parth` paths replaced by relocatable defaults and env vars.
- New: `analysis/figures.py`, `scripts/08_analysis.py`, `scripts/09_report.py`,
  `tests/make_synthetic.py`, `tests/smoke.sh`, `README.md`, `requirements.txt`, docs.
